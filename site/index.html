初始化轨迹

  1. 环境体检SSH 认证、API 直连、代理根因定位（宿主注入的 127.0.0.1:8522 无监听）
  2. 工程骨架src 布局、pyproject 单一配置源、ruff + pytest、pre-commit
  3. 任务框架一个入口托管 N 个任务，靠任务名分发，零第三方运行时依赖
  4. 持续集成CI 闸门与本地 scripts/dev.py all 完全一致
  5. 部署通道Pages 与 Releases 两条发布路径均已配置，等待首次触发
